# Prompt: Markdown a PDF imprimible para engargolar

Copia todo lo de abajo y pégalo junto con el archivo `.md` (`manual_uso.md` o `manual_tecnico.md`).

---

Convierte el archivo Markdown adjunto en un PDF listo para imprimir y engargolar.

**Página**
- Tamaño carta (8.5 × 11 in), vertical.
- Márgenes: izquierdo 30 mm (lado del engargolado), superior, inferior y derecho 20 mm.
- Impresión a una cara.
- Número de página abajo al centro; título corto del documento en el encabezado, en gris.

**Blanco y negro**
- Sin color. Todo el texto en negro.
- Tablas: bordes negros de 0.5 pt, encabezado con fondo gris claro (~15 %), legibles en fotocopia.
- Código: fuente monoespaciada, fondo gris muy claro (~8 %) y borde fino.
- Reemplaza los emojis por texto equivalente.

**Tipografía**
- Cuerpo: serif (Times, Georgia o similar), 11 pt, interlineado 1.3.
- Títulos: sans serif en negrita. H1 18 pt, H2 14 pt, H3 12 pt.
- Ecuaciones y variables en cursiva.

**Estructura**
- Página 1, portada: título, "Microcontroladores 2", nombres del equipo [LLENAR] y fecha.
- Página 2: índice.
- Cada sección H2 empieza en página nueva.
- Ninguna tabla ni bloque de código se parte entre páginas; ningún título queda solo al pie de una página.
- Las casillas `- [ ]` se dibujan como cuadros vacíos para palomear con pluma.
- Los espacios `___` se convierten en líneas para escribir a mano (~3 cm).

**Contenido**
- Respeta el texto exactamente: no resumas, no agregues ni quites nada.

Entrega el PDF final.
